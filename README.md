# SpendWise Pro - Interactive Personal Finance Dashboard

## Project Description
SpendWise Pro is an interactive, responsive personal financial command center and budgeting web application. It enables users to track monthly budgets, record multiple expense items categorized by type, monitor live financial health via dynamic status indicators, and manage expenses seamlessly using vanilla JavaScript arrays, loops, conditionals, and DOM manipulation.

## Technologies Used
- **HTML5:** Semantic document structure, input fields, and dashboard containers.
- **CSS3:** Custom Properties (CSS Variables), Flexbox, CSS Grid, and professional Emerald Green & White UI themes.
- **JavaScript (ES6+):** Arrays of objects, `for` and `forEach` loops, conditional logic (`if/else`), DOM manipulation methods, and Event Listeners/Delegation.
- **Version Control & Hosting:** Git, GitHub, and Netlify for continuous cloud deployment.

## Deployment Process Summary
1. **Repository Verification:** Ensured all project files (`index.html`, `style.css`, `script.js`, and `README.md`) were organized in the root directory and pushed to a public GitHub repository.
2. **Netlify Connection:** Logged into Netlify, selected "Add new site" -> "Import an existing project", and authorized GitHub access.
3. **Site Configuration:** Selected the `Spendwise-dashboard2` repository, left build settings as default (static site deployment), and triggered the initial build.
4. **Custom Subdomain:** Updated the default Netlify site name in Site Settings to a meaningful identifier (`spendwise-ibrahim`).
5. **Continuous Deployment Verification:** Pushed a minor CSS refinement to GitHub and verified that Netlify automatically rebuilt and updated the live site within seconds.

## Challenges Encountered During Deployment
- **Challenge:** Initially managing branch configurations and ensuring automatic deployments triggered correctly on every git push.
- **Resolution:** Linked the Netlify project directly to the `main` branch of the GitHub repository, enabling seamless continuous deployment (CI/CD) on all subsequent updates.
